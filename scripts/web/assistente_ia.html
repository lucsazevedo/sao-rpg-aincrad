Se a conexão falhar mas o ollama list funciona no terminal, é CORS: o Ollama recusa pedidos vindos do navegador por padrão. Feche o Ollama, defina a variável de ambiente do Windows OLLAMA_ORIGINS = * (Painel de Controle → Variáveis de Ambiente → Nova), e reinicie o Ollama. Modelo sem suporte a imagem (a maioria, incluindo qwen2.5:14b) simplesmente ignora imagens anexadas — pra análise de imagem, use um modelo de visão (ex: ollama pull qwen2.5vl:7b ou llava) e selecione-o acima.
